# CERVEL Public 0.1.0-alpha.2 — Prepared Candidate

Python package version: `0.1.0a2`

Prepared tag: `v0.1.0-alpha.2`

Status: **prepared-not-published**.

This candidate introduces the CERVEL Local Developer Sandbox: a bounded localhost-only compatibility runtime for the deliberately published experimental contracts.

## Added

- `cervel` command-line entry point.
- `cervel dev` local developer sandbox bound to `127.0.0.1`.
- `GET /capabilities`, `POST /capture`, and `POST /lookup` public routes.
- Ephemeral in-memory local records with opaque sandbox identifiers.
- Deterministic public token-overlap lookup behavior for development only.
- Contract validation on accepted requests and generated public responses.
- Public `ErrorEnvelope` responses for invalid requests and unknown routes.
- Optional `sandbox` extra using the existing pinned public validation dependency.
- HTTP integration tests and installed-wheel CLI smoke tests.

## Boundary

The sandbox is not the proprietary CERVEL engine. It does not expose or implement production authorization, permission-aware activation, retrieval/ranking, persistence, provenance processing, knowledge compilation, synchronization, model routing, agent orchestration, private storage, service topology, or production identifiers.

All stored records are process-local and disappear when the sandbox stops.

## Release discipline

The already-published `0.1.0a0` and `0.1.0a1` releases remain immutable. This candidate does not replace either version in place. Publication requires a separate explicit release action after the exact post-merge `main` commit passes the full release gate.
