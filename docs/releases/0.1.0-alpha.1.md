# CERVEL Public 0.1.0-alpha.1 — Prepared Candidate

Python package version: `0.1.0a1`

Prepared tag: `v0.1.0-alpha.1`

Status: **prepared-not-published**.

This candidate adds optional, purely local JSON Schema validation helpers for the deliberately published CERVEL experimental contracts.

## Added

- `validate_payload(contract, value)` for generic local validation against a named public contract.
- Specialized helpers for Capture Envelope, Lookup Request, Knowledge Reference, Lookup Result, Error Envelope, and Capability Discovery.
- `validation_errors()` for non-throwing schema-error inspection.
- `get_public_schema()` and `SUPPORTED_CONTRACTS` for local access to the six published experimental schemas.
- Structured `ContractValidationError`, `UnsupportedContractError`, and `ValidationDependencyError` exceptions.
- Optional `validation` dependency extra using `jsonschema==4.25.1`.

## Boundary

Validation is local only. The helpers do not make network requests and do not expose or implement CERVEL authentication, authorization, permission-aware activation, retrieval, ranking, persistence, provenance processing, knowledge compilation, synchronization, model routing, agent orchestration, private storage, service topology, or other non-public runtime behavior.

The embedded schema representations are limited to the same six JSON Schemas already deliberately published in this repository. Repository tests require those embedded schemas to remain exactly equal to their authoritative public schema documents.

## Release discipline

`0.1.0a0` remains immutable and published. This candidate does not replace it in place. Merging this candidate does not create the prepared tag, GitHub Release, or PyPI publication. Publication requires a separate explicit release action after the exact post-merge `main` commit passes the full release gate.
