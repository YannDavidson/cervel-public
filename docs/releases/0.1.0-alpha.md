# CERVEL Public 0.1.0 Alpha

Status: **release candidate documentation only — not yet published**.

This alpha is intended to validate the deliberately public CERVEL interoperability surface and developer experience before any stable compatibility promise. It does not publish or expose non-public CERVEL runtime behavior, infrastructure, retrieval logic, authorization internals, persistence mechanisms, provenance implementation, model routing, agent orchestration, or production topology.

## Included public surface

- experimental `0.1-draft` public schemas and conformance fixtures;
- public conformance validator and CI gate;
- typed Python convenience SDK models;
- executable synthetic Python examples and five-minute quickstart;
- Apache-2.0 licensing metadata and license-bearing Python artifacts;
- contribution governance, DCO policy, and automated DCO enforcement.

## Alpha expectations

The public SDK package uses PEP 440 version `0.1.0a0`. Human-facing release communication uses the `0.1.0-alpha` family. The recommended first tag is `v0.1.0-alpha.0`.

This is prerelease software. Public APIs and schemas may change before a stable release. Versioned contracts remain authoritative for the versions they explicitly declare.

## Publication boundary

No package registry publication, Git tag, GitHub Release, deployment, or production endpoint is created by this document or by PR #19. Those are separate explicit release actions governed by `RELEASING.md`.
