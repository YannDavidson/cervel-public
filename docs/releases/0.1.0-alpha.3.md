# CERVEL Public 0.1.0-alpha.3 — Prepared Candidate

Python package version: `0.1.0a3`

Prepared tag: `v0.1.0-alpha.3`

Status: **prepared-not-published**.

This candidate adds the public Python `LocalClient`: a dependency-free, loopback-only developer abstraction over the existing CERVEL Local Developer Sandbox.

## Added

- `LocalClient`, defaulting to `http://127.0.0.1:8765`.
- `capabilities()`, `capture()`, and `lookup()` methods over the already-published public sandbox routes.
- Typed public responses using `CapabilityDiscovery`, `KnowledgeReference`, and `LookupResult`.
- Stable client exceptions for configuration, connection, HTTP/public-error, and malformed-response failures.
- Explicit rejection of non-loopback targets (`127.0.0.1`, `localhost`, and `::1` are allowed).
- Client success/failure tests, distribution checks, installed-wheel coverage, and an executable developer example.
- Updated public SDK API documentation for the client surface.

## Boundary

`LocalClient` is a localhost developer abstraction only. It does not expose or implement authentication, authorization, permission-aware activation, production routing, production persistence, proprietary retrieval/ranking, private CKO/CKURI internals, Knowledge Compiler behavior, CCP implementation, Intelligence Gateway behavior, model routing, agent orchestration, private storage, service topology, or production identifiers.

The base SDK remains dependency-free and uses only Python standard-library HTTP, JSON, and URL facilities for this client.

## Release discipline

The already-published `0.1.0a0`, `0.1.0a1`, and `0.1.0a2` releases remain immutable. This candidate does not replace any published artifact in place. Publication requires a separate explicit release action after the exact post-merge protected `main` commit passes the full release gate.
