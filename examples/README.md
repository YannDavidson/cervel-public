# CERVEL Examples

Examples in this directory will demonstrate public CERVEL contracts using synthetic or non-sensitive data.

Examples must never contain production credentials, private endpoints, customer information, real private knowledge, proprietary production source, or copied internal configuration.

Planned examples include:

- capturing a public webpage as untrusted knowledge;
- retrieving an authorized knowledge object;
- asking an intelligence layer with scoped context;
- following a public Trace reference back to supporting knowledge;
- supplying persistent context to an agent through a public interface.
